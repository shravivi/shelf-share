# Shelf Share

A neighborhood lending library tracker. Neighbors list tools, books and gear they are happy to share, then check items out and back in. People borrow instead of buying, and nobody forgets who has the ladder.

- Search and filter: available, checked out, overdue
- Due dates with overdue highlighting
- Works offline, no account, no server
- Export and import JSON backups so a block captain can share the list

## Run it
Open `index.html`, or `python3 -m http.server 8000`.

## Publish
GitHub repo **Settings → Pages → Deploy from branch → main / root**.

## Ideas to extend
Add a QR code per item for check-out at the shelf, or sync through a shared Google Sheet.
